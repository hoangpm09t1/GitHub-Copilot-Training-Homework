# Reflection

Using GitHub Copilot was much faster and more convenient compared to traditional coding methods.

Traditionally, I would search online for examples, read documentation, and manually write and debug the code myself. This process usually takes more time because I need to switch between multiple websites and verify whether the examples are correct.

With GitHub Copilot, I could generate code suggestions instantly inside Visual Studio Code by writing comments or prompts. During the Design Patterns exercise, Copilot helped generate boilerplate code, suggested method structures, and reduced repetitive typing.

One major advantage was productivity. Copilot allowed me to focus more on understanding the logic instead of spending too much time writing repetitive code syntax.

However, I also learned that AI-generated code should still be reviewed carefully. In some cases, Copilot generated inefficient or insecure code, so manual verification and testing were still necessary.

Overall, GitHub Copilot improved my development workflow and made coding faster and more efficient.
