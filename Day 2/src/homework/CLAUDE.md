# CLAUDE.md — Project Rules

## Rule: Save Plan During Planning

Whenever a plan is created for an exercise in this project, save the full plan as a markdown file in the `plans/` folder at the project root.

**Naming convention:** `plans/exercise{N}-{short-description}.md`

**Each plan file should include:**
- Context (why the change is needed)
- Target file path(s)
- Full implementation code
- Key annotations/patterns checklist
- Verification steps
